2~4h

SQL: fundamentos

A primeira ferramenta técnica, de propósito. SQL é a linguagem universal dos dados e é aqui que nasce a mentalidade analítica.

O que estudar

  • PostgreSQL + DBeaver
  • SELECT, WHERE, ORDER BY
  • Tipos de dados
  • LIMIT, DISTINCT
  • JOIN e GROUP BY

Como instalar PostgreSQL e DBeaver

PostgreSQL é o banco de dados. DBeaver é a interface visual para escrever e rodar SQL. Siga o guia abaixo para o seu sistema operacional.

3~4h

Mentalidade analítica: qualidade de dados

Saber escrever SQL não é o mesmo que confiar no resultado. Desconfiar do dado é o que mais separa júnior de sênior.

O que estudar

  • Valores ausentes (NULL)
  • Outliers (método IQR)
  • Tipo de coluna
  • Volume de linhas/colunas
  • Duplicidade
  • Padronização
